## 🚀 Project Overview

**Maashho** is a modern online shopping web application designed to deliver a smooth and visually appealing user experience. The project focuses on clean UI, reusable React components, responsive design, and modern frontend best practices. It simulates a real-world e-commerce platform with essential sections commonly found in professional shopping websites.

This project is built as a **frontend-focused application**, ideal for showcasing React.js skills, UI/UX understanding, and project structuring.

---

## ✨ Key Features

* 🏠 **Home Page** with product highlights and clean layout
* 🛒 **Product Card Page** with reusable card components
* 🌗 **Dark Mode / Light Mode** toggle
* 🔔 **Notification system** for user feedback
* 🧭 **Reusable Header** with logo and brand identity
* 📦 **Professional Footer** with branding and essential links
* 🔍 **Advanced Filters & Sorting**

  * Sort by price, discount, and rating (ascending / descending)
  * Category-based filtering (Beauty, Electronics, Furniture, Groceries, etc.)
* 📱 **Fully Responsive Design** (mobile, tablet, desktop)
* ⚡ **Fast performance** using Vite

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Routing:** React Router
* **State & Utilities:** Axios, Toast Notifications
* **Icons:** React Icons
* **Linting:** ESLint
* **Build Tool:** Vite (Rolldown)

## 📂 Project Setup

```bash
# Clone the repository
git clone https://github.com/ramkachhwaha/Maashho-Shopping-Site.git

# Navigate to project directory
cd Maashho-Shopping-Site

# Install dependencies
npm install

# Start development server
npm run dev
```
